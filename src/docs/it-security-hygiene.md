# IT Lesson: Security Hygiene

The most effective habits: use a password manager with long unique passwords or passphrases; turn on multi-factor authentication (MFA) everywhere, preferably an authenticator app or security key; install updates promptly; encrypt laptops and phones; lock your screen; and back up important files.

Phishing is the most common attack. Warning signs: urgency or threats, unexpected attachments, a sender address that is slightly wrong, links whose real address does not match the text, and requests for passwords or payments. Do not click; report it to IT. Verify unusual payment or bank-detail requests by calling a known number.

Least privilege means people get only the access they need for their job. Remove access when someone changes role or leaves.

On public Wi-Fi, use a VPN and prefer HTTPS sites. Never share passwords or MFA codes with anyone, including people claiming to be IT. Report lost devices immediately so they can be locked or wiped.
