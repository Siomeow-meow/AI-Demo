# Help: Sending Files and Data to the Assistant

Yes, you can send the assistant your own files. Click the paperclip "Attach" button in the chat box, drag files onto the chat window, or paste them. No separate import page is needed.

Supported files: CSV and TSV, Excel (.xlsx), JSON, PDF, Word (.docx), PowerPoint (.pptx), and plain text, Markdown, HTML and log files. Scanned PDFs and images cannot be read because they have no text.

What happens next: tables (CSV, Excel, JSON lists) can be described, searched, filtered, grouped and totalled, and every row is also indexed so questions can find individual records. Documents (PDF, Word, PowerPoint, text) are split into passages and searched, and answers show which file they came from.

After attaching, ask a question such as "Describe my data", "Which region has the highest total?", "Summarize the document" or "What does the policy say about remote work?". If a table has employee, inventory or sales columns, it replaces the sample company records for lookups.

Files are read on your computer and stay in this browser. Attached knowledge can be reviewed and removed on the Knowledge page.
