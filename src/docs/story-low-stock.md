# User Story: Low Stock Alert

As a warehouse manager, I want to be notified when an item falls below its reorder level, so that I can restock before we run out.

## Acceptance criteria

- Each inventory item has a configurable reorder level.
- When stock drops below the reorder level, the item appears on the low-stock list.
- The warehouse manager receives an email once per item per day.
- The low-stock list can be exported to CSV.
