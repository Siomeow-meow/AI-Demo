# IT Lesson: A Method for Troubleshooting

Work in a repeatable order. 1) Define the problem: what exactly happens, what should happen, and when did it start? 2) Find out what changed recently. 3) Reproduce it, and check whether it affects one person or many. 4) Form a theory and test the simplest, cheapest causes first. 5) Change one thing at a time and note the result. 6) Fix it, confirm with the user, and document the solution.

Quick checks that solve many issues: is it plugged in and powered on; restart the application or device; is the internet working; is the account locked or the password expired; is there a pending update; does it work on another device or account; does the error message say something specific (search the exact text).

Isolate by splitting the problem in half: user versus system, wired versus Wi-Fi, one site versus all sites. Do not make several changes at once, or you will not know which one helped. Escalate with the facts you collected.
