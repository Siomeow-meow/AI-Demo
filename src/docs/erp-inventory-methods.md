# ERP Lesson: Inventory Methods

Costing methods decide which cost is charged to the goods you sell. FIFO (first in, first out) assumes the oldest stock is sold first, so cost of goods sold uses older prices. LIFO (last in, first out) assumes the newest is sold first; it is allowed in some countries but not under IFRS. Weighted average divides total cost by total units. Standard costing uses a fixed planned cost and records variances.

When prices rise, FIFO shows higher profit and higher ending inventory than LIFO.

Planning ideas: the reorder point is daily demand multiplied by lead time, plus safety stock. EOQ (economic order quantity) is the square root of (2 x annual demand x order cost / holding cost per unit). Safety stock protects against demand and supply variation.

Control ideas: ABC analysis ranks items by value (A items need the tightest control), and cycle counting checks a small part of the stock every day instead of one big yearly count.
