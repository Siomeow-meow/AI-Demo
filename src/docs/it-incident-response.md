# IT Lesson: Security Incident Response

Phases: 1) Prepare (plans, contacts, tools, training). 2) Detect and analyse (confirm what happened and how serious it is). 3) Contain (stop it spreading, such as isolating the device from the network). 4) Eradicate (remove malware, close the hole, reset credentials). 5) Recover (restore systems from clean backups, monitor closely). 6) Lessons learned (write up what happened and improve).

If you suspect a compromise: do not ignore it, report to IT or security straight away, disconnect the device from the network but do not power it off if investigators may need memory evidence, write down times and what you saw, and do not try to clean up evidence yourself.

Keep a log of actions and decisions. Decide who communicates with management, customers and regulators; some laws require notification of breaches within a set time. After the incident, fix the root cause, for example a missing patch, weak password or untrained user.
