# Networking Lesson: Wi-Fi, VLANs, VPNs and Firewalls

Wi-Fi bands: 2.4 GHz reaches further but is slower and crowded; 5 GHz is faster with shorter range; 6 GHz (Wi-Fi 6E and 7) adds more clean channels. Use WPA3 where possible or WPA2 with a strong passphrase; never WEP or open networks for business data. Put guests on a separate guest network.

A VLAN splits one physical network into separate logical networks (for example staff, guests, cameras and servers). It improves security and reduces broadcast traffic. Traffic between VLANs passes through a router or layer 3 switch where rules can be applied.

A VPN creates an encrypted tunnel over the internet. Remote-access VPNs connect one user to the office; site-to-site VPNs connect two networks.

A firewall allows or blocks traffic using rules based on addresses, ports and sometimes applications. A good starting rule is to deny everything by default and allow only what is needed.
