# What is an ERP?

Enterprise Resource Planning (ERP) software is a single system that a company uses to run its core business processes. It brings finance, inventory, purchasing, sales, human resources and manufacturing into one shared database, so every department works from the same up-to-date data.

Without an ERP, each team often keeps its own spreadsheets or separate tools, which leads to duplicate entry and conflicting numbers. With an ERP, a sales order can automatically update inventory, trigger purchasing, and appear in the finance ledger.

Well-known ERP systems include SAP, Oracle NetSuite, Microsoft Dynamics 365 and Odoo. Implementation is usually done in modules, such as accounting, inventory and payroll, which a company can roll out step by step.
